
# Установить dotnet-ef — CLI для Entity Framework Core

```shell
dotnet tool install --global dotnet-ef
```

Обновить до последней версии

```shell
dotnet tool update --global dotnet-ef
```

Проверить, что `dotnet-ef` установлен

```shell
dotnet ef
```

# Собери билд проекта

В корне проекта, где находится файл решения `.slnx`

```shell
dotnet build
```

# Создай первую миграцию:

Находясь в папке `TemplateService.Infrastructure.Postgres` запусти командку:

```shell
dotnet ef database update --project ../TemplateService.Infrastructure.Postgres --startup-project ../TemplateService.Web
```

Флаг `--startup-project` нужен исключительно для `dotnet ef`, чтобы `EF` знал, откуда брать строку подключения и конфигурацию DI. Для обычной сборки он не нужен и ломает команду.
